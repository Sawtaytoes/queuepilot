The provider block — three candidate controls

The unit that repeats is the whole block: “Plays under profile” + “Libraries this queue can search & hold”. A queue holds N of them, each one homogeneous, so mixing falls out of composition rather than out of a multi-select. What is not settled is the provider control itself — that is the choice below. The screenshot beside this file was rendered against the app’s real stylesheet; this standalone copy inlines equivalent styles so it keeps working after the next build changes the content-hashed CSS filename.
